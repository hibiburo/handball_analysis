# シーンの MP4 書き出し 要求内容

- 作業ディレクトリ: `.steering/20261003-scene-mp4-export/`
- 作成日: 2026-10-03
- ステータス: 承認済み（2026-10-03）

---

## 1. 背景と目的

アナリストは、分析で見つけた GK の弱点の根拠となるシーンを、選手（シューター陣）に動画ファイルとして渡し、Google Drive で共有したい。

試合動画は自チームで撮影したもので、**元の動画ファイルが手元にある**。YouTube の動画を外部ツールでダウンロードすることは利用規約で禁止されているため、YouTube からは取得せず、次のどちらかのファイルから切り抜く。

- 撮影した元の動画ファイル
- 動画をアップロードしたアカウントの **YouTube Studio からダウンロード** したファイル（YouTube が持ち主向けに提供している機能）

どちらも YouTube に上げた動画と時刻がそろっているため、記録した動画時刻のまま切り抜ける。

なお、動画リンク付きの CSV を書き出す案（PR #11）は、利用者の判断で採用しないことにした。

## 2. 変更内容

- 分析画面のシーン一覧に「**MP4 で書き出す**」ボタンを追加する
- 押すと、今の絞り込み条件に合うシーンを試合ごとにまとめて表示し、**試合ごとに元の動画ファイルを選ぶ**
- 選んだファイルから、各シーンを **記録時刻の前余白〜後余白（既定 4秒前〜3秒後、設定に従う）** で切り抜いた MP4 を作り、**zip にまとめてダウンロード** する
- 変換はすべてブラウザの中で行い、動画ファイルを外部に送信しない
- 作成中は進み具合（n / 全件）を表示し、途中でやめられる

## 3. ユーザーストーリー

- アナリストとして、絞り込んだシーンを MP4 の切り抜きファイルとして書き出したい。Google Drive に入れて選手に共有するため
- 選手として、共有された MP4 を自分のスマホで見たい。GK の弱点を自分の目で確かめるため

## 4. 受け入れ条件

| # | 受け入れ条件 |
|---|---|
| AC1 | 分析画面のシーン一覧に「MP4 で書き出す」ボタンがあり、シーンが0件のときは押せない |
| AC2 | 押すと、対象のシーンが試合ごとに表示され、試合ごとに元の動画ファイルを選べる。ファイルを選んでいない試合のシーンは書き出されず、そのことが分かる |
| AC3 | 書き出すと、各シーンの MP4（記録時刻の前余白〜後余白を含む）が zip にまとめてダウンロードされる。前余白・後余白の設定を変えると、切り抜く範囲も変わる |
| AC4 | MP4 のファイル名から、試合日・動画時刻・シュート位置・コース・結果が分かる（例: `20260920_23m41s_レフトバック_コース1_失点.mp4`）。zip には、各ファイルとシーンの情報の一覧（CSV）も入れる |
| AC5 | 作成中は進み具合が表示され、「中止」でやめられる。中止したら何もダウンロードしない |
| AC6 | 1試合分（数GB）の動画ファイルでも、ブラウザのメモリ不足にならずに書き出せる（PC の Chrome で確認） |
| AC7 | 書き出した MP4 は、iPhone・Android のスマホで再生できる |
| AC8 | 動画ファイルは外部に送信されない。変換の部品（ffmpeg.wasm）は、使うときに初めて読み込み、アプリの初回表示を遅くしない |
| AC9 | lint・型チェック・単体テスト・E2E・CI がすべて成功する |

## 5. 制約事項・範囲外

- YouTube からのダウンロード機能は作らない（利用規約のため）。元のファイルは利用者が用意する（元の動画ファイル、または YouTube Studio からダウンロードしたもの）
- 速さを優先して再エンコードしない切り抜き（キーフレーム単位）にするため、開始位置が最大で数秒早まることがある（前余白があるため、シーンが欠けることはない）
- 主な利用環境は PC（Mac の Chrome）とする。iPad は大きなファイルの扱いが不安定なため、動作は保証しない
- Google Drive への自動アップロードは行わない（Google のログイン設定が必要になるため）。ダウンロードした zip を利用者が Drive に入れる
- YouTube に上げた動画と元のファイルの時刻がずれている（編集して上げた）場合は、正しく切り抜けない。README に注意書きを加える
