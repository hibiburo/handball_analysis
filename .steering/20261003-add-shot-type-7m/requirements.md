## 1. 変更内容

シュート種別（`shotType`）に **7mスロー**（コード値 `seven_m`）を追加する。

| | 選択肢 |
|---|---|
| 変更前（5つ） | サイドシュート、ミドルシュート、ポスト、カットイン、速攻 |
| 変更後（6つ） | サイドシュート、ミドルシュート、ポスト、カットイン、速攻、**7mスロー** |

- 表示名は、用語集で 7m を指す呼び方（シュート位置の「7mスロー」）にそろえる
- 「速攻」と同じく、シュート位置にも「7mスロー」がある。どちらで記録するかは利用者が決める

## 3. 設計

- `src/domain/enums.ts` の `shotTypes`・`shotTypeLabels` に `seven_m: '7mスロー'` を追加するだけで、記録画面・絞り込み・各一覧・Excel の書き出しはすべて自動で反映される（すべてこの定義を参照しているため）
- 記録画面の種別の選択肢は3列のため、6つでちょうど2行になる
- 既存の値は変わらないため、IndexedDB・書き出しファイル（`schemaVersion: 2`）の移行は不要。ただし、7mスローを含む書き出しファイルは、この変更より前のアプリでは取り込めない（利用者は1人のため問題なし）
