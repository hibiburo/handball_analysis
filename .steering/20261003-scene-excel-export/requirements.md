# シーン一覧の Excel 書き出し 要求内容

- 作業ディレクトリ: `.steering/20261003-scene-excel-export/`
- 作成日: 2026-10-03
- ステータス: 承認済み（2026-10-03）

---

## 1. 背景と目的

アナリストは、分析で見つけたシュートの場面を、Excel の一覧にまとめたい。動画のどこからどこまでがそのシーンかが分かれば、一覧を見ながら動画の該当箇所を確認したり、チームで共有したりできる。

これまでに検討した「動画リンク付きの CSV」（PR #11）と「MP4 の書き出し」（PR #12）は、利用者の判断で採用しないことにした。代わりに、シュート種別と動画の開始・終了時間をまとめた Excel ファイルを書き出す。

## 2. 変更内容

- 分析画面のシーン一覧に「**Excel で書き出す**」ボタンを追加する
- 押すと、**今の絞り込み条件に合うシーン**（シーン一覧に表示されているもの）を、シーン一覧と同じ順番（試合日 → 動画時刻）で、1行1シーンの Excel ファイル（.xlsx）としてダウンロードする
- 列は次の3つ

| 列 | 内容 | 例 |
|---|---|---|
| シュート種別 | 表示名（サイドシュート・ミドルシュート・ポスト・カットイン・速攻）。未入力は空 | カットイン |
| 動画開始時間 | 記録時刻 − 前余白（既定4秒）。0秒より前にはしない | 23:37 |
| 動画終了時間 | 記録時刻 + 後余白（既定3秒） | 23:44 |

- 範囲はシーン再生と同じで、設定の前余白・後余白に従う
- 1行目は見出しにし、スクロールしても見出しが見えるように固定する

## 3. ユーザーストーリー

- アナリストとして、絞り込んだシュートの場面を、シュート種別と動画の開始・終了時間の一覧として Excel に書き出したい。一覧を見ながら動画を確認したり、チームで共有したりするため

## 4. 受け入れ条件

| # | 受け入れ条件 |
|---|---|
| AC1 | 分析画面のシーン一覧に「Excel で書き出す」ボタンがあり、シーンが0件のときは押せない |
| AC2 | 押すと、シーン一覧と同じシーンが同じ順番で、1行1シーンの .xlsx としてダウンロードされる |
| AC3 | 列は「シュート種別」「動画開始時間」「動画終了時間」の3つで、1行目が見出し。シュート種別の表示名は用語集と同じ |
| AC4 | 動画開始時間・終了時間は、記録時刻の前余白前・後余白後で、`m:ss`（1時間以上は `h:mm:ss`）の形で表示される。前余白・後余白の設定を変えると、時間も変わる |
| AC5 | ファイルは Excel で開け（文字化けしない）、見出しの行が固定されている |
| AC6 | ファイル名は `handball_analysis_scenes_{GK名}_{日付}.xlsx` |
| AC7 | Excel を作る部品は使うときだけ読み込み、アプリの初回表示を遅くしない |
| AC8 | lint・型チェック・単体テスト・E2E・CI がすべて成功する |

## 5. 制約事項・範囲外

- 列は利用者が指定した3つだけにする（試合日・シュート位置・結果などは含めない。必要になれば追加する）
- 複数の試合のシーンを書き出すと、どの試合のシーンかは一覧からは分からない（上記のとおり、必要になれば「試合日・対戦」の列を追加する）
- 動画ファイルやリンクは作らない
- .xlsx の作成には、保守されている部品 `write-excel-file` を使う（npm 版の `xlsx`（SheetJS）は古く既知の脆弱性があるため使わない）
