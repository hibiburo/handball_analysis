# シーン再生の余白の既定値変更 要求内容

- 作業ディレクトリ: `.steering/20261002-change-highlight-margins/`
- 作成日: 2026-10-02
- ステータス: 承認済み（2026-10-02）

---

## 1. 変更内容

シーン再生の余白の既定値を、次のとおり変更する。

| 設定 | 現在の既定値 | 変更後の既定値 |
|---|---|---|
| 前余白（`highlightPreSeconds`） | 3秒 | **4秒** |
| 後余白（`highlightPostSeconds`） | 2秒 | **3秒** |

シーンの再生範囲は「記録時刻の3秒前〜2秒後（5秒）」から「**記録時刻の4秒前〜3秒後（7秒）**」になる。

### 理由

利用者（アナリスト）の要望。シュートに至るまでの流れと、シュート後の GK の動きを、もう少し長く見たいため。

## 2. ユーザーストーリー

アナリストとして、シーン再生で記録時刻の4秒前から3秒後まで見たい。シュートまでの流れと GK の反応をミーティングで見せやすくするため。

## 3. 受け入れ条件

| # | 受け入れ条件 |
|---|---|
| AC1 | 設定を一度も保存していないブラウザでは、分析画面のシーン再生が記録時刻の4秒前から3秒後まで（7秒）になる |
| AC2 | 同じく、記録画面でシュート一覧の行を押すと、記録時刻の4秒前に移動する |
| AC3 | 「データ管理・設定」に表示される前余白・後余白の初期値が 4・3 になる |
| AC4 | 設定画面で前余白・後余白を変えられる（0〜30秒）ことは変わらない |
| AC5 | 文書（docs/）の既定値の記述が 4秒・3秒 になっている |
| AC6 | lint・型チェック・単体テスト・E2E・CI がすべて成功する |

## 4. 制約事項・範囲外

- **保存済みの設定は変更しない**。設定が一度でも保存されたブラウザ（設定を変えた、または全データを書き出した場合）は、保存済みの値（例: 3秒・2秒）を使い続ける。利用者が意図して 3秒・2秒を選んだ場合と区別できないため、自動では書き換えない。必要な利用者は設定画面で変更する
- 書き出しファイルの形式（`schemaVersion`）は変えない。設定の項目と値の範囲は同じため
- 過去の作業記録（`.steering/20260928-initial-implementation/`）は当時の内容として残し、書き換えない
