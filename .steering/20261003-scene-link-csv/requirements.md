# シーンの動画リンクの書き出し 要求内容

- 作業ディレクトリ: `.steering/20261003-scene-link-csv/`
- 作成日: 2026-10-03
- ステータス: 承認済み（2026-10-03。リンクの形式は 6章の変更履歴のとおり利用者と相談して変更）

---

## 1. 背景と目的

アナリストは、分析で見つけた GK の弱点の根拠となるシーンを、選手（シューター陣）に共有して各自のスマホで見てもらいたい。分析画面では1シーンずつ再生できるが、そのシーンを選手に渡す手段がない。

試合動画は自チームで撮影して YouTube に上げたものである。YouTube の動画をダウンロード・切り出し保存することは利用規約で禁止されているため、**動画ファイルは作らず、YouTube の再生位置を指定した「動画リンク」を一覧にして書き出す**。アナリストはその一覧を Google Drive に入れて選手に共有する。

元の動画ファイルから MP4 の切り抜きファイルを作る機能は、この一覧で運用したうえで、あとで検討する（本作業の範囲外）。

## 2. 変更内容

- 分析画面のシーン一覧に「**共有用に書き出す（CSV）**」ボタンを追加する
- 押すと、**今の絞り込み条件に合うシーン**（シーン一覧に表示されているもの）を、1行1シーンの CSV ファイルとしてダウンロードする
- 各行に、そのシーンの少し前から再生する **動画リンク** を含める
  - 開始位置はシーン再生と同じ「記録時刻 − 前余白」（既定 4秒前、設定に従う）。終了位置では止まらない
  - 形式: `https://youtu.be/{動画ID}?t={開始秒}`（スマホでは YouTube アプリで開く）
- CSV は Google スプレッドシートと Excel で文字化けせずに開け、リンクを押して再生できる

これは機能設計書 5.5 で「次回以降」としていた「集計用 CSV の書き出し」を、動画リンクの列を加えて実装するものである。

## 3. ユーザーストーリー

- アナリストとして、絞り込んだシーンを動画リンク付きの一覧で書き出したい。Google Drive に入れて選手に共有するため
- 選手として、共有された一覧のリンクを押して、そのシーンを自分のスマホで見たい。GK の弱点を自分の目で確かめるため

## 4. 受け入れ条件

| # | 受け入れ条件 |
|---|---|
| AC1 | 分析画面のシーン一覧に「共有用に書き出す（CSV）」ボタンがあり、シーンが0件のときは押せない |
| AC2 | 押すと、シーン一覧と同じシーンが同じ順番（試合日 → 動画時刻）で、1行1シーンの CSV としてダウンロードされる |
| AC3 | 各行に、試合日・対戦・大会・動画時刻・シュート位置・シュート種別・コース・結果・GKの対応・利き手・ポジション・数的状況・前後半・メモ・動画リンク が含まれる。表示名は用語集と同じ |
| AC4 | 動画リンクを開くと、記録時刻の前余白（既定4秒）前から再生される。参照元のない開き方（スプレッドシートのアプリなど）でも再生できる。前余白の設定を変えると、リンクの開始位置も変わる |
| AC5 | CSV は UTF-8（BOM 付き）で、Google スプレッドシートと Excel で文字化けしない。メモに `=` などで始まる文字列があっても、数式として実行されない |
| AC6 | ファイル名は `handball_analysis_scenes_{GK名}_{日付}.csv` |
| AC7 | lint・型チェック・単体テスト・E2E・CI がすべて成功する |

## 5. 制約事項・範囲外

- 動画ファイル（MP4 など）は作らない（YouTube の利用規約のため。元ファイルからの切り抜きはあとで検討）
- Google Drive への自動アップロードは行わない。アナリストがダウンロードしたファイルを Drive に入れる（Google のログイン設定が必要になるため）
- 選手がリンクで動画を見るには、YouTube の動画が「公開」または「限定公開」である必要がある（「非公開」の動画は再生できない）。README に注意書きを加える
- 全データの JSON 書き出し・取り込みは変更しない

## 6. 変更履歴

- 2026-10-03: 当初は再生範囲（開始・終了）を指定する埋め込み用の URL（`https://www.youtube.com/embed/{動画ID}?start=&end=`）で、そのシーンだけを再生する「切り抜きリンク」にする予定だった。実装後の確認で、この URL は参照元（Referer）なしで直接開くと YouTube が「エラー 153（動画プレーヤーの設定エラー）」を返して再生できないことが分かった（スプレッドシートのアプリや LINE から開いた場合に起きうる）。利用者と相談のうえ、どこから開いても再生できる通常の視聴リンク（開始位置のみ指定、終了位置では止まらない）に変更した
- 範囲どおりに止まる再生は、アプリを Vercel で公開したあとに、アプリ内の「切り抜き再生ページ」（アプリのページに YouTube を埋め込み、前余白〜後余白だけを再生する）とそのリンクの列を追加して実現する（別の作業）
