# シュート種別の変更 要求内容

- 作業ディレクトリ: `.steering/20261002-change-shot-types/`
- 作成日: 2026-10-02
- ステータス: 承認済み（2026-10-02）

---

## 1. 変更内容

記録画面の「詳細」にある **シュート種別**（`shotType`）の選択肢を、打ち方の分類から攻撃の形の分類に入れ替える。

| | 選択肢 |
|---|---|
| 変更前（8つ） | ジャンプ、ステップ、ランニング、倒れ込み、ループ、バウンド、スピン、その他 |
| 変更後（5つ） | **サイドシュート、ミドルシュート、ポスト、カットイン、速攻** |

- 「その他」は置かない。当てはまらない場合は未入力にする（シュート種別は任意項目のため）
- **シュート位置（コート図と、7mスロー・速攻・ロングシュートのボタン）は変更しない**。シュート位置は「どこから打ったか」、シュート種別は「どんな攻撃の形で打ったか」として、別々に記録する

### 理由

利用者（アナリスト）の要望。チームのスカウティングで使っている分類に合わせるため。

## 2. ユーザーストーリー

- アナリストとして、シュートを「サイドシュート・ミドルシュート・ポスト・カットイン・速攻」の5つで記録したい。チームで使っている分類で傾向を見るため
- アナリストとして、分析画面でこの5つのシュート種別で絞り込みたい。攻撃の形ごとの GK の弱点を見るため

## 3. 受け入れ条件

| # | 受け入れ条件 |
|---|---|
| AC1 | 記録画面の「詳細」のシュート種別に、サイドシュート・ミドルシュート・ポスト・カットイン・速攻 の5つだけが表示され、1つを選べる（もう一度押すと選択を外せる） |
| AC2 | 分析画面の絞り込みの「シュート種別」に、同じ5つが表示され、絞り込める |
| AC3 | シュート一覧・シーン一覧・シーン再生の表示に、新しい種別の名前が表示される |
| AC4 | 古い種別（ジャンプなど）で記録済みのシュートは、アプリを開いたときに種別だけが未入力になり、シュート位置・コース・結果などの他の項目は変わらない |
| AC5 | 古い形式（`schemaVersion: 1`）の書き出しファイルを取り込むと、古い種別は未入力として取り込まれる。新しく書き出すファイルは `schemaVersion: 2` になる |
| AC6 | 分析画面に保存されていた絞り込み条件のうち、古い種別の条件は消える（それ以外の条件は残る） |
| AC7 | 用語集（glossary.md）と画面の表示名が一致している（用語集のテストが成功する） |
| AC8 | lint・型チェック・単体テスト・E2E・CI がすべて成功する |

## 4. 制約事項・範囲外

- シュート位置（`zone`）の選択肢、コート図、入力の流れは変更しない。そのため「速攻」はシュート位置とシュート種別の両方にある状態になる（どちらで記録するかは利用者が決める）
- 古い種別を新しい種別に自動で読み替えることはしない（打ち方と攻撃の形は対応しないため）
- 過去の作業記録（`.steering/20260928-initial-implementation/` など）は当時の内容として残し、書き換えない
