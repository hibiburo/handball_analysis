# プロダクト要求定義書（PRD）

- プロダクト名: handball_analysis（仮称）
- バージョン: 0.1（初版ドラフト）
- 作成日: 2026-09-28
- ステータス: 承認済み（2026-09-28）

## 1. プロダクトビジョンと目的

### ビジョン

**「相手GKのクセを、試合前にチーム全員が知っている状態をつくる」**

### 目的

大学・高校ハンドボールの分析担当者が、YouTube上の試合動画を見ながら相手ゴールキーパー（GK）に対するシュートを素早く記録し、
コース・位置・シュート種別ごとの失点傾向（＝弱点）を可視化して、該当シーンを即座に選手へ見せられるようにする。

### スコープ

| 対象 | 対象外（初期リリース） |
|---|---|
| 相手チームGKのキーピング分析 | 自チームGKの評価、フィールドプレーヤーの個人評価 |
| 動画を見ながらの試合後入力 | 試合中のリアルタイム入力 |
| YouTube動画の埋め込み再生 | ローカル動画ファイル、クラウドへの動画アップロード |
| 1ユーザー・ログインなし・ブラウザ内保存 | アカウント、チーム共有、サーバー保存 |
| アプリ独自形式での書き出し／取り込み | 公式記録・外部Excelの取り込み、PDFレポート出力 |
| 日本語UI | 多言語対応 |
| 手入力 | AI・画像認識による自動解析 |

## 2. ターゲットユーザーと課題・ニーズ

### ペルソナ

**大学／高校ハンドボール部のアナリスト・マネージャー**

- 次の対戦相手の試合動画（YouTube公開・限定公開）を入手して分析する役割
- 分析結果を監督・コーチ・シューター陣にミーティングで伝える
- 主な端末はタブレット（iPad等）とノートPC
- 統計の専門家ではないが、ハンドボールの用語・戦術には詳しい

### 現状の課題

| # | 課題 | 詳細 |
|---|---|---|
| P1 | 記録に時間がかかる | 動画とExcel／紙を行き来し、再生・一時停止・記入を繰り返している |
| P2 | 弱点が見えにくい | 表の数字だけではどのコースが弱いか直感的に分からない |
| P3 | 根拠となる映像をすぐ出せない | 「左上に弱い」と伝えても、該当シーンを探し直す手間がかかる |
| P4 | 複数試合の合算が面倒 | 試合ごとにファイルが分かれ、同一GKの傾向をまとめて見られない |

### ニーズ

- 動画とデータ入力を **1画面で** 完結させたい
- 記録した瞬間に **動画の時刻と紐づけ**、あとでワンタップでそのシーンに戻りたい
- ゴール9分割の **ヒートマップ** で弱いコースを一目で把握したい
- 条件（位置・シュート種別・利き手など）で **絞り込み**、該当シーンを **連続再生** したい

## 4. 成功の定義

| # | 指標 | 目標値 |
|---|---|---|
| S1 | 入力速度 | 1試合（シュート約50本）の記録を **試合時間の1.5倍以内**（60分試合 → 90分以内）で完了できる |
| S2 | 1本あたりの入力操作 | 1本のシュートを **平均6タップ以内** で記録できる |
| S3 | 弱点把握 | 分析画面を開いてから **3操作以内** で、失点率の高いコース上位3つを特定できる |
| S4 | シーン提示 | 任意の絞り込み条件のハイライト再生を **2操作以内** で開始できる |
| S5 | 複数試合分析 | 同一GKの **5試合以上** を合算しても、集計・ヒートマップ表示が遅延なく（1秒以内）更新される |

## 5. ビジネス要件

- **提供形態**: 無料のWebアプリ（まずは作者自身と所属チームでの利用を想定）
- **運用コスト**: サーバー・DBを持たない静的ホスティングで運用し、ランニングコストをほぼゼロにする
- **データ所有**: データは利用者のブラウザ内のみに保存し、運営側は一切保持しない
- **共有**: 他のアナリストとの共有は書き出しファイルの受け渡しで行う
- **将来の拡張余地**（本PRDの対象外）: ログイン・チーム共有、複数チーム向けサービス化、自チームGK評価、PDFレポート出力

## 8. 機能要件

### 8.1 試合管理（F1）

- 登録項目: 日付、大会名（任意）、ホームチーム、アウェイチーム、YouTube URL、メモ（任意）
- 一覧は日付の降順。チーム名・大会名で検索できる
- 試合を削除すると、その試合のシュート記録も削除する（削除前に確認する）

### 8.2 GK管理（F2）

- 登録項目: チーム名、名前、背番号（任意）、利き手（右・左・不明）
- 試合への紐づけ: 1試合に複数GK（交代を想定）

### 8.3 動画再生（F3）

- YouTube IFrame Player を使って埋め込み再生する
- 操作: 再生／一時停止、±2秒・±5秒スキップ、再生速度（0.25x〜2x）
- 現在の再生時刻を取得して記録に使う

### 8.4 シュート記録（F4）

1本のシュートにつき以下を記録する。

| 項目 | 値 | 必須 |
|---|---|---|
| 動画時刻 | 記録ボタン押下時の再生位置（秒）、手動で微調整可 | ○ |
| 試合時間 | 前半／後半（任意で分） | − |
| 担当GK | 試合に紐づくGKから選択（直前の選択を保持） | ○ |
| シュート位置 | コート図のゾーンをタップ（下記） | ○ |
| ゴールコース | 3×3の9分割から選択（枠外・ブロックの場合は不要） | 条件付き |
| シュート種別 | 下記から選択 | − |
| 結果 | 下記から選択 | ○ |
| GKの対応 | 手・足・体・反応なし（結果がセーブの場合） | − |
| シューターの利き手 | 右・左・不明 | − |
| シューターのポジション | LW・LB・CB・RB・RW・PV | − |
| 数的状況 | 同数・数的優位・数的不利 | − |
| メモ | 自由記述 | − |

**シュート位置（ゾーン）**

- レフトウイング／レフトバック（9m付近）／センター（9m付近）／ライトバック（9m付近）／ライトウイング
- 6m（ポスト・カットイン）：左・中央・右
- 7mスロー
- 速攻（ブレイクスルー・カウンター）
- ロングシュート（自陣・センターライン付近から）

**ゴールコース（3×3）**

```
┌───┬───┬───┐
│ 1 │ 2 │ 3 │   上段
├───┼───┼───┤
│ 4 │ 5 │ 6 │   中段
├───┼───┼───┤
│ 7 │ 8 │ 9 │   下段
└───┴───┴───┘
  左  中央  右   ※ 分析者（シューター）から見た向き
```

**シュート種別**: サイドシュート、ミドルシュート、ポスト、カットイン、速攻（攻撃の形。当てはまらない場合は未入力）

**結果**: 失点（ゴール）、セーブ、ポスト・バー、枠外、DFブロック

### 8.5 シュート一覧・編集（F5）

- 試合内のシュートを動画時刻順に一覧表示
- 行のタップで該当シーンへジャンプ（既定4秒前から）
- 各シュートの編集・削除、直前の操作の取り消し（Undo）

### 8.6 ヒートマップ（F6）

- ゴール9分割に対し、コースごとの「シュート数」「失点数」「セーブ率」を表示
- 表示の切り替え: セーブ率／失点率／シュート本数
- サンプル数の少ないコースは薄い表示や注記で参考値と分かるようにする
- 補助表示: コート図のゾーン別セーブ率

### 8.7 条件絞り込み集計（F7）

- 絞り込み条件: 試合（複数選択）、GK、シュート位置、ゴールコース、シュート種別、結果、利き手、ポジション、数的状況、前半／後半
- クロス集計: 「シュート位置 × ゴールコース」「シュート種別 × 結果」など2軸の表
- ヒートマップのコースをタップすると、そのコースで絞り込む

### 8.8 ハイライト再生（F8）

- 現在の絞り込み結果を時系列プレイリストとして再生
- 各シーン: 記録時刻の −3秒 〜 +2秒（設定で変更可）
- 操作: 前へ／次へ、ループ再生、シーン情報（位置・コース・結果）のオーバーレイ表示
- 複数試合をまたぐ場合は、動画を自動で切り替える

### 8.9 複数試合合算（F9）

- GKを軸に、紐づく全試合を合算して F6〜F8 を利用できる
- 試合ごとの内訳（試合別セーブ率）を確認できる

### 8.10 書き出し／取り込み（F10）

- 書き出し: 全データ／試合単位／GK単位でJSON。選手への共有・集計用に、絞り込み結果のシーン一覧を動画リンク（そのシーンの少し前から再生する YouTube のリンク）付きの CSV でも書き出す。動画ファイルは作らない（YouTube の利用規約のため）
- 取り込み: 本アプリが書き出したJSONのみ対象。スキーマとバージョンを検証する
- 重複の扱い: 同一IDは「上書き」「スキップ」を選択

### 8.11 キーボードショートカット（F11, Should）

- 例: Space＝再生／停止、←/→＝±2秒、Enter＝記録確定、1〜9＝ゴールコース選択

## 9. 非機能要件

### 9.1 対応環境

- 端末: タブレット（iPad 10インチ以上、横向きを主とする）、PC（1280px幅以上）
- ブラウザ: 最新版の Safari（iPadOS／macOS）、Chrome、Edge
- スマートフォンは閲覧のみ（最低限の表示崩れ防止）

### 9.2 パフォーマンス

- シュート記録の保存は200ms以内に反映される
- 1GKあたり10試合・500本のデータで、絞り込み・ヒートマップ更新が1秒以内
- 初回表示は3秒以内（一般的な回線）

### 9.3 データ保存・信頼性

- データはブラウザ内（IndexedDB）に保存し、サーバーには送信しない
- ブラウザのデータ消去で失われるリスクがあるため、書き出し（バックアップ）を促すUIを設ける（例: 最終バックアップ日時の表示）
- 書き出しJSONにはスキーマバージョンを含め、将来のデータ移行に備える

### 9.4 ユーザビリティ

- タップ対象は最小44×44px
- 動画と入力パネルを1画面に同時表示（タブレット横向きで動画60%／入力40%程度）
- 日本語UIのみ。ハンドボール用語は現場で使われる表記に合わせる（用語は glossary.md で定義）

### 9.5 セキュリティ・プライバシー

- ユーザー入力（チーム名・メモ等）の表示時にエスケープし、XSSを防ぐ
- 取り込みファイルはスキーマ検証を行い、不正なデータは拒否する
- YouTube埋め込みは公式IFrame APIのみを使い、動画自体を保存・ダウンロードしない
- 個人情報（選手名）はブラウザ内のみに保存し、外部に送信しない

### 9.6 制約事項

- 動画はYouTubeで埋め込みが許可されている必要がある（埋め込み不可の動画は分析できない）
- YouTubeの再生にはネット接続が必要（データの閲覧・集計はオフラインでも可能）
- YouTubeの利用規約に従い、動画の加工・切り出し保存は行わない（ハイライトは再生位置の指定で実現する）
